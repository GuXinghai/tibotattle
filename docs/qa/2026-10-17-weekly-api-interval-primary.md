## 实施结果

- 周等值 API 提升到一级界面，套餐选择紧邻产品名称。主图、精确时间滑条、
  不平滑及五种高斯尺度联动；保留全局时段和刷新，不增加页面轮询。
- 完整明细保留逐区间计算、全部分页、原有额度／用量历史、重置、五小时、
  校准与对比工具；秒及毫秒、时区、计价依据和覆盖状态在详情保留。
- 服务端复用逐条记录的速度专用 API 定价；没有把套餐速度扣减倍率充作 API
  价格。未确认速度采用有披露的 Standard 情景。不同上下文费率可共同计入；
  同一费率族的生效时期变化单独隔离。
- 事件属于 `(start,end]`，显示阶梯属于 `[start,end)`。平台期延续原始锚点；
  交错旧读数和冲突读数不能降低已确认的周期扣减基准，只有独立重置证据
  可以建立新基准。无可靠分母、归属或完整计价的区间保留原因而非填零。
- 用户提供的免费自动批准审查规则仅作用于本图分子，按截图的本机日本时间
  采用 2026-10-07 05:56 的公告边界。原始审查用量和其他成本统计保留；无法
  确认审查来源的相关区间单独标明，不认证其他普通代码审查免费。
- 高斯核按真实时间积分、在完整连续段内归一化，然后裁切显示范围。直接
  对 CDF 差积分，避免极短区间相减失精度；不跨缺口或重置，不回写统计。
- 新扩展是闭合、有界、带版本和来源围栏的派生契约。旧缓存可读，下一次
  正常发布补算扩展；保存的外来来源、未来结果或非法结构被拒绝。
- 普通更新保留可用结果、详情、分页及选中时间，错误有类别和重试。修复了
  浏览器核对发现的详情重排回环：同一报告的 resize 不再重复重建子详情。

## 冻结真实数据对账

同一报告截止点为 2026-10-17 19:16:18.433（日本时间）。使用 SQLite 一致性
备份的受保护本机副本；原始数据库仅以只读方式打开。重新流式独立汇总
已有索引事实，没有重读原始日志全量。派生结果共 1,895 个区间：

| 套餐 | 全部区间 | 可计算区间 |
|---|---:|---:|
| Plus | 293 | 267 |
| Pro Lite | 1,602 | 1,245 |

1,512 个有效区间的精确金额、扣减端点、事件数和公式全部吻合，覆盖 129,547
次有效区间内用量变化；有效区间之间不重叠。其他区间逐项保留重置、冲突、
归属、计价或等待变化状态，不一起清空。55 组真实分段、不同尺度的独立
Simpson 积分核对通过，最大绝对差为约 1.28 × 10^-8 美元。
