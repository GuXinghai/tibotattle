# 主窗口自定义背景实施计划

此计划保留为原始授权与存储边界的记录，已由 2026-10-18 后续设置整合决定取代。
当前行为以[用户指南](../user-guide.md#settings-and-optional-features)和
[接口参考](../reference/api-surface.md#integrated-desktop-settings-contracts)为准；
下文原计划中的设置独立窗口、图片上限及恢复默认按钮不再适用。

## 状态与边界

本计划记录已确认的交互方向和实施工作。背景功能源码、静态资源闭包及
定向测试已接入；Windows 原生受保护存储已用超过 1 MB 的合成图片验证原字节往返。
用户已授权实施、保留现有改动、打包并打开本地候选。打包和真实界面验收尚在进行，
本文不代表已安装、签名或发布。

现有外观约束见[单色外观决定](../decisions/2026-10-18-monochrome-dashboard-appearance.md)。
该决定已为将来的个性化背景预留主题角色。本功能允许用户主动设置彩色背景，
保留非工作负载文字为黑色、工作负载红黄绿的方向；实施时须同步说明
默认单色外观与自定义背景的优先级，不能让旧的单色断言误伤用户选择。

## 已确认的产品范围

- 背景覆盖整个主窗口，包括左侧栏和右侧内容区，各主导航页面一致。
- 自定义背景色使用现成的系统调色盘，不自行重做取色器。
  同时提供 HEX 和 RGB 数值输入，三个入口双向同步。
- 提供八种浅色预设：纯白、雾灰、暖石、奶油、薄荷、晴空、淡紫、浅樱。
- 本地背景图片支持选择、更换和移除；图片可以叠加可调浅色遮罩。
- 图片保持比例、居中铺满。窗口比例变化时裁切多余区域，不拉伸、不留白，
  不因每次调整窗口大小而重新读取文件。
- 设置面板不再保留整片固定白底，背景能透过内容区显示。
- 提供恢复默认。已有的去标识、侧栏刷新、设置入口及刷新结果行为保持一致。

## 交互与状态规则

1. 点击预设立即预览对应颜色，并同步调色盘、HEX、RGB 和选中标记。
   预设为纯色背景，选择后退出图片背景；保留原始用户图片文件。
2. HEX 接受六位色值，可自动补全开头的 `#`；RGB 仅接受 0–255 的整数。
   编辑中允许暂时不完整，校验失败不覆盖最后一个有效颜色，也不保存无效值。
3. 图片显示在背景色之上；调色盘只改变底色，不暗中移除已选择的图片。
   移除图片后重新显示当前底色，同步刷新预设选中状态。
4. 取消选图、无法解码、类型或尺寸超限时保留上一份有效设置，显示本地化结果。
   更换失败不能先清空当前图片。
5. 遮罩仅作用于图片层，不影响文字和工作负载图形本身；调整后即时预览。
   预览中的 35% 默认值、0–90% 范围作为首版建议，不作为已经实现的契约。
6. 正式应用中的有效设置须本地持久化，重启后仍生效；保存失败明确反馈，
   不把仅在内存中的预览描述为保存成功。输入保存须合并或串行处理，防止旧请求覆盖新选择。
7. 恢复默认清除自定义背景覆盖，回到既有外观偏好对应的默认背景。
   只处理本功能拥有的配置和资源，不重置其他设置，不删除用户源图片。

## 控件底色检查要求

用户指出：无边框不代表没有底色，“恢复默认”在换色后仍会露出白色矩形。
此问题作为明确的验收项，不只检查按钮边框。

- “恢复默认”等轻量按钮显式使用透明背景，并核对继承与共享样式覆盖。
- 检查普通、悬停、按下、聚焦、禁用和选中状态，保留清楚的键盘焦点提示。
- 检查输入框、下拉框、滚动容器、粘性标题、图表容器、空状态和弹窗，
  避免遗漏固定白色面板；需要实体底色的控件应使用明确的主题角色。
- 在暖色、冷色、饱和自定义色和图片背景上复查。
  不能只用白色默认背景验收；取色色块本身须始终反映有效选色。

## 实现分工与顺序

### 1. 核对现有边界并冻结输入

记录工作区改动，保留 DeepSeek 和用户已有修改。阅读 Web、Electron、
本地状态及国际化相关范围的指导。沿用既有设置窗口，不因预览把设置画在
主窗口内就迁移正式设置入口。确认设置读取、首次绘制、切页和广播的调用链。

重点入口为 `apps/electron/desktop-contract.js`、`desktop-settings-store.js`、
`desktop-settings-backends.js`、`preload.cjs`，以及
`apps/web/public/desktop-appearance.js`、`electron-settings.*` 和主界面样式。

### 2. 扩展设置与图片资源边界

由 Electron 主进程控制系统文件选择，renderer 不能提交任意路径读取请求。
颜色、遮罩和图片引用使用封闭配置；需要版本演进时提供前向迁移与负向测试，
不得改标签、降级或清空旧设置。

图片持久化使用受保护状态存储的既有能力，保存应用拥有的副本和不透明引用。
用户补充要求：图片独立存储，原始字节保持不变，不为适应 1 MB 单记录上限压缩画质。
采用独立资源的有界二进制分块和内容校验，不提高原有设置记录或底层读操作的上限；
配置只保存资源引用，导入日志保证中断后能够回收不再引用的本功能资源。
实施前确认该存储是否支持受限二进制资源；如不支持，先扩展所属存储边界，
不能退回普通文件写入。读取也只允许本功能拥有的资源，不放开任意文件 URL、
远程图片 URL、导航或全局 CSP。图片不得进入统计、导出、日志或遥测。

首版建议只接受静态 PNG、JPEG、WebP，限制文件字节数、像素数及解码资源；
预览的 20 MB 上限仅作起点，须结合解码内存评估确定最终上限。
资源更换与配置提交应保持可恢复：先验证新图，保存成功后切换引用，
再处理明确属于本功能的旧副本，保留失败恢复路径。

### 3. 接入主题与设置界面

复用现有主题角色，以单一背景层覆盖主窗口，内容与侧栏按需透明；
避免为每个页面复制背景或叠加多份遮罩。用 CSS 完成窗口缩放适配，
释放被替换的图片对象，快速切换时只允许最新选择生效。

加入预设、系统调色盘、数值输入、选图与遮罩控制，处理加载、取消、失败、
恢复默认和保存状态。使用规范国际化目录更新三种语言，并生成浏览器镜像。

明暗模式需要在实施前明确优先级：建议自定义背景启用时采用用户要求的黑色文字，
恢复默认后继续遵循已有系统／浅色／深色偏好，不改写该偏好。
深色自定义颜色或低遮罩图片的可读性须在预览中检查，不能静默改变用户色值。
设置窗口的同步呈现可复用同一背景规则；托盘、恢复窗口、公共网站和管理界面
不属于本次背景定制范围。

### 4. 验证后交付本地候选

先验证设置合同、迁移、路径拒绝、图片限制、失败保留旧值、并发顺序及资源回收；
再验证颜色输入同步、纯色与图片切换、恢复默认、国际化和控件状态。
测试采用合成图片和临时测试配置，不改真实用户配置作为自动化测试手段。

运行受影响的 Electron／Web 定向测试和 `pnpm run product:ui:test`；
更新文档并运行 `pnpm run docs:check`、`pnpm run test:preflight`，
涉及依赖边界时增加 `pnpm run architecture:check`。
最后用要求的 Node.js 26.2.0 准备新的 Windows x64 本地候选，
核对源码与 ASAR，真实打开检查。保持未签名本地候选与安装、签名、发布证据分离。

## 最终验收清单

- [ ] 颜色预设、调色盘、HEX、RGB 同步；无效输入不污染保存状态。
- [ ] 图片、遮罩和颜色覆盖整个主窗口；导航切换及刷新不会丢失背景。
- [ ] 放大、缩小、最大化、还原窗口时图片不变形、无空白、无重新读取闪烁。
- [ ] 更换失败、取消选图和持久化失败保留最后有效状态，结果反馈明确。
- [ ] 重启后恢复配置；图片源文件移动后，应用拥有的副本仍可显示。
- [ ] “恢复默认”及其他轻量控件在各种背景和交互状态下不露固定白底。
- [ ] 黑色文字、工作负载红黄绿、焦点提示及窄窗口布局可用。
- [ ] 默认明暗模式、已有侧栏动作及其他设置没有回归。
- [ ] 本地候选实机验收记录绑定准确源码和 ASAR；没有据此声称已安装或发布。
