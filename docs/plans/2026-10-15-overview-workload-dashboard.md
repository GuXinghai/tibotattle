# 总览重构完整计划

状态：总览预览与任务工作时长口径已获用户确认，计算、采集、刷新及五卡界面已实施。旧目录权限、迁移入口及比较基准存储问题已修复；默认真实资料正常启动、手动刷新和两轮自动刷新已检查，连续运行超过十四分钟。实际证据与数据质量限制见[权限恢复与运行核查](../qa/2026-10-15-real-profile-permission-recovery.md)。像素级界面、签名、安装与发布验收仍各自独立，本文是实施合同，不能代替这些凭据。

## 1. 产品边界与统一口径

- 保留五张卡片：剩余额度、套餐实际工时、额度消耗、当前负载、实际消耗相对预期。视觉按已确认预览，不增加主题色或说明段落。
- 按用户指定的单人、单账户、Plus／Pro 连续订阅场景分析未归属历史；明确记录的不同账户、套餐、倍率、额度池及计价口径仍隔离。分析假设不改写历史归属事实。
- 工时指任务进行中的工作时间，包括模型思考、生成内容、工具执行、命令、复制文件、测试，以及任务内必要的等待和请示确认。任务结束后的空闲和可确认的休息、暂停不算。
- 并行工作区间取并集；父任务等待子任务仍算工作，不能再叠加子任务时长。不以窗口、会话或进程打开的总时间当工时。
- 不显示预计耗尽日期或倒计时。工时表示当前剩余额度在相应工作负载下可支持的工作小时。
- 历史分析取截止前 168 小时；日柱取本地时区今天及此前六个自然日，今天统计到本次截止。日界按时区日历计算，不假设每天固定 24 小时。
- 有效历史样本可以先参与计算，正常卡片不增加覆盖提示；真实故障、过期结果和数据缺口不能伪装成零或成功。
- 显示窗口不改变历史保留，其他页面的分析能力保留。

| 指标 | 消耗依据 | 时间依据 |
| --- | --- | --- |
| 套餐实际工时 | 近七天实际额度扣减 | 同范围任务工作区间并集 |
| 三档聚类 | 本地等值 API 用量 | 五分钟桶内任务工作区间并集 |
| 每日额度消耗 | 实际扣减，按本地用量分配三档 | 不按工时比例分配扣点 |
| 当前速率、当前工时 | 等值 API 用量除以周容量换算 | 最近十五分钟内任务工作区间并集 |
| 实际消耗相对预期 | 实际扣减对比等值 API 换算 | 比较累计量，不需要工时分母 |

## 2. 工作区间、进行中任务与存储

### 2.1 任务边界

- 优先使用 `task_started` 至 `task_complete` 或 `turn_aborted` 的时间戳。完成、失败和取消之前已经工作的时间均计入，不因任务失败而删除。
- 有受支持的明确暂停／恢复事件时扣除暂停段；普通工具等待、审批请求和没有新增 token 不构成暂停。不读取自然语言内容猜测休息。
- 开始记录缺失、完成记录具有语义明确且有效的任务总时长时，允许以完成时间减总时长恢复起点，标记 `reported_duration` 来源；冲突、负时长和无效时间戳不计算。
- 开始、结束齐全且顺序有效时使用真实起止时间。报告时长与时间戳差异超过两秒只计入时长差异诊断，不排除整段工作；缺开始时仍仅使用有效报告时长恢复。负起点、逆序及无法配对的边界仍报错。
- 使用索引已保存的父子关系排除同任务、同事件类型的祖先重放；完成事件还需报告时长一致。无祖先证据或完成时长矛盾时不能猜测去重。存储事实不删改，子会话新增任务正常保留。
- 工作边界不依赖模型是否单一、是否调用工具、是否产生 token 或推理计时是否完整。不能复用模型性能统计的这些排除条件。
- 不连接相邻任务之间的空档；任务内的正常等待则保留。

### 2.2 进行中与未闭合任务

- 连续采集期间，本次确认的新任务开始建立临时工作区间，直到完成、取消、明确暂停或本次截止；长时间执行工具而无 token 仍算进行中。
- 普通读取失败不等于结束或休息；该轮显示采集错误并保留旧结果，不继续发布未经确认的新时长。
- 应用重启、休眠或确认采集中断后，不把未知间隔自动补成工时；遗留未闭合任务先封存至最后确认时刻。新任务内活动可从该活动时刻恢复临时计时，不跨未知间隔补时。
- 迟到的有效完成记录能恢复完整任务边界时，重算受影响区间，补回可确认的连续工作时间；替换投影，不能再次累加。
- 旧日志只有开始、没有结束或有效总时长时，只使用开始至最后已确认任务内活动；无正时长则保持未闭合。不能一直延长到现在。
- 合同区分临时与已结束区间；正常界面不因此增加覆盖提示。

### 2.3 事实、关联与归桶

- 在现有统一索引中增加工作生命周期及区间，不建立浏览器扫描器或第二份 token 账本。
- 最小保留派生工作项键、起止／最后确认时间、终态、证据类型、解析版本及关联范围；不保留原始任务 ID、文本或命令。
- 先对工作区间求并集，再按各五分钟桶重叠长度求工时；并行、父子任务和跨桶都不重复。
- 用量按权威 usage 事实的真实观测时间归桶，不将任务总 token 平均铺满任务，也不把十五分钟旧桶平均拆成五分钟。
- 已确认在工作的零用量桶仍计工时，可以是零强度样本。缺失计价、缺失核算不等于零；五分钟桶也不自动算五分钟工时。
- 文件复制、重放及分叉继承历史按逻辑发生去重；真正新发生的子任务保留，再以时间并集处理。
- 本功能不再要求补存纯模型执行区间；现有模型性能统计继续使用其独立定义。

## 3. 五张卡片的计算

### 3.1 剩余额度

- 使用真实周额度观测显示近七天折线和“当前 66%”；按额度窗口时长识别周额度，不固定依赖 primary／secondary 位置。
- 重置、额度池或套餐变化分段；相邻观测超过十五分钟断线，不插值造点。
- 当前值与悬停保留实际观测时间。上游整数百分比不具备隐藏精度；内部保留实际输入数值，不提前按显示精度取整。

### 3.2 聚类分档

对近 168 小时同分析场景有效工作桶：`x_b = U_b / H_b`，其中 `U_b` 是等值 API 用量、`H_b` 是工作小时。

- `H_b > 0` 且核算、计价有效才参加；`U_b = 0` 可以参加，没有工作区间的桶不参加。
- 采用确定性一维最优三类 k-means，以 `H_b` 加权、动态规划求解，不增加聚类依赖，不依赖随机中心。
- 至少九个有效桶和三个不同强度值；每类至少三个桶、合计一分钟工时。约束不满足时三档暂缺，综合值仍独立计算。
- 中心由低到高映射轻、中、重；距离相同归较低档，求解同分取较早排序切分点。算法与阈值版本固定并测试。
- 不按 token 数加权、不排除零用量工作时间、不自动裁掉高负载样本。
- 一次发布共用一份分类版本；历史工时、日柱和当前负载不混用中心。

### 3.3 套餐实际工时

同重置周期相邻真实额度观测之间：`A_j = 后一次已用百分比 - 前一次已用百分比`。

- 不跨重置、套餐或额度池相减；周期内旧低值单独记录并排除，不将其回升重复计为消耗。同时间矛盾等真正冲突仍分类报错，不裁成零或负消耗。
- 综合速率使用工作范围可完整对齐的有效观测区间：`r_all = ΣA_j / ΣH_j`；`H_j` 是同区间工作并集小时。
- 部分旧任务缺边界时，使用其他可对齐的有效观测区间；不能用全量扣减除以部分工时。
- 综合值无需先完成聚类，也不依赖周容量。不能因分类、容量或非必要计价缺失而一起隐藏。
- 同一重置周期的已用额度按此前已确认最高值计算新增量。旧低值不推进配对起点，恢复到旧高值不再次计入；重置或套餐改变不跨段相减。同一时间的矛盾、不可配对区间仍报错并留缺口。窗口之前同周期的证据仅建立防重复基准，不算作窗口内消耗。
- `adjustments` 分别记录已排除重放事件数、保留的报告时长差异数及排除的旧低值数；这是可核查的处理记录，不能改写原始观测。剩余额度与比较曲线使用合格读数，旧低值绘为缺口并保留最近合格读数的真实时间。
- 三档细分在本地用量完整可计价的观测区间内分配：`A_jb = A_j × U_jb / ΣU_jb`，再按桶所属档位汇总；分配只使用同一实际观测起止之间的用量，保留未分类部分。
- 三档分母包括所属桶的工具、测试、等待及零用量工作时间，不能只累计出现 token 或扣点的时段。
- `r_k = 该档分配到的实际扣点 / 该档工作小时`；当前剩余额度为 `R` 个百分点，`T_k = R / r_k`，`T_all = R / r_all`。
- `R = 0` 且速率有效时显示零；速率为零、缺失或非有限数时显示 `—`，不显示无穷大。某行缺失不阻断其他行。
- 例如工作两小时、实际扣减六点，综合速率三点／工时；剩余 66% 对应 22 小时。
- 四条共用小时刻度，宽度为本行工时除以四行最大有效工时；起点、轨道、数值列一致，综合只加粗。各行是同一份额度的不同负载情景，不相加。

### 3.4 额度消耗

- 日柱总量来自实际扣减，按同观测区间本地用量权重分到日期与负载桶，不能按工时比例分配。
- 红、黄、绿无缝堆叠；无法分类扣减用灰色。三档加未分类等于可归日总量。
- 跨日无法可靠归日的部分保留相关日缺口与区间证据，不硬记在读数返回当天，不默默丢弃。
- 已覆盖且实际没有扣点可以为零；没有观测与覆盖不能画零柱。
- 标题“额度消耗”，今天正常统计；不加“包含今天”或分摊说明段落。

### 3.5 当前负载

刷新截止前十五分钟内，`U` 为用量、`H` 为工作小时、`C` 为同套餐周额度等值 API 容量：

`r_now = 100 × U / C / H`；`T_now = R / r_now`。

- 不足十五分钟使用已有有效区间；工具与必要等待计入 `H`。
- `C` 复用现有历史校准及质量门槛，保留套餐、倍率、计价基准与版本；不能使用七天成本总额或剩余额度代替。
- 当前分档比较 `U / H` 与历史同版本中心；不能直接拿历史实际扣点速率当此处阈值。
- 任务仍在工作但新增用量为零时，允许零速率，不等于无负载；无法换算工时显示 `—`。
- 本次扫描成功确认没有进行中工作项、也没有状态不明的未闭合项时，显示“无负载”，隐藏速率和工时；过去十五分钟有已完成任务不阻止当前无负载。
- 五分钟无 token、额度未跳变或模型暂时没输出均不能单独证明无负载。
- 有任务但时长或用量不足显示“工作中，正在采集”；中心不足显示“工作中，尚未分档”，独立有效的速率、工时仍显示。
- 扫描失败或无法确认旧任务是否结束，显示错误或“状态未知”，不伪称休息。
- 缺容量只阻断百分点速率和当前工时，任务状态与独立有效分类仍显示。
- UI 为大号档位、下一行当前速率、再下一行“按当前负载可继续工作 × 小时”。

### 3.6 实际消耗相对预期

对齐真实观测起止：`E = 100 × U / C`，`A = 实际扣减`，`D = (A / E - 1) × 100%`。

- 比较累计消耗，不需要工时分母，本次口径变更不改变公式；差异不回灌当前速率。
- 每五分钟桶取最后一次真实额度观测，最多一点；保留真实时间，无观测留空，不凑整点。
- 首个合格观测建立起点，窗口一小时；满后起点前移四十分钟，保留二十分钟，相对新起点重算。
- 起点必须有真实观测；边界无点时取其后首个合格点，不插值。超过一小时的采集中断另起段。
- 容量固定为段起点当时已可用的合格版本；前移也不使用未来版本。容量版本缺失时暂缺，不拿未来校准补早期基准。
- 重置、套餐变化另起段；持久化窗口位置和容量版本，重启不重复前移；不删除历史。
- `E = 0` 时留断点；若 `A > 0`，记录未匹配用量。`E > 0` 且读数尚未跳变可为观测意义的 `-100%`，不当作计算错误。
- 卡片只保留标题和曲线坐标，不加累计快慢摘要、额外时间文字、上下说明或前移按钮。

## 4. 架构、接口和兼容

- provider 解析生命周期，统一索引保留事实与游标，application 编排，quota-analysis 公开入口计算，companion 发布，web 渲染。时钟、文件及平台适配器显式注入。
- `/api/local/overview` 增加版本化 `workload` 投影：五卡数据、截止、水位、算法／分类／容量版本、指标状态和安全错误列表；保留既有消费者兼容性。
- 既有刷新合同新增封闭枚举 `overview`，沿用 Host、Origin、方法、能力和大小校验，不增加无保护入口。
- 工作事实、必要关联和解析游标采用前向迁移及回放；不能改名旧模型 `duration` 当新口径，也不能直接复用被性能质量条件筛掉后的 `turn_duration`。
- 回填有界、可恢复、逻辑发生去重；不支持记录、压缩不可用和边界冲突分别报告。
- 新增、迟到、修正只重算受影响投影；不改变 token 账本，不把 timing token 再当核算来源。
- DTO 验证有限数、单位、时间顺序与状态；缺失用 `null` 和原因，不用零、NaN、Infinity。
- 原始账户 ID、提示、响应、命令、私有路径和原始异常不进入公开合同、诊断、夹具或提交，测试只用合成数据。

## 5. 统一刷新

唯一总览协调器位于 companion，桌面控制生命周期；渲染器和各卡片不另设刷新计时器。

`额度读取 → 近期用量及工作区间增量 → 聚合分类 → 合同校验 → 一次发布`

- 固定五分钟；自动、手动共用流程；执行中的重复请求加入同一任务，不并发、不追加重复队列。
- 本轮结束后重新计五分钟，成功、部分成功、失败、取消均如此；手动刷新使旧截止失效。退出不再安排下一轮。
- 常规总览刷新上限六十秒，超时保留提交游标与旧结果，明确结束，下次继续，不无限加载或紧密重试。
- 以额度观测时刻或失败时本轮截止作为统计边界，仅使用不晚于边界的事实。分别保留来源水位，不拼出缺乏对应覆盖的新指标。
- 五卡一次发布；独立成功项可更新，依赖失败项保留旧值和旧时间，不能给旧值盖新时间。
- 首次七天初始化、旧生命周期回放和低频历史检查分批后台推进，在批次边界让出执行权；不阻塞近期刷新，不每轮重扫历史。
- 托盘继续刷新；休眠恢复、重新启动立即一轮，不补造停机额度点。单调时钟避免回拨和旧定时器重复触发。
- 设置展示总览固定五分钟，新保存值规范为 300 秒，旧配置兼容读取；深度维护保留既有低频策略，共用互斥写入。
- 发布失败保留上一完整版本；已独立提交的观测与增量供下一轮继续使用。

## 6. 数据状态与错误分类

无负载、正在采集、正在回填、样本不足、未分类和零分母属于有原因的数据状态；读取、解析、计算、存储、传输故障属于错误。

| 分类 | 示例稳定码 | 行为 |
| --- | --- | --- |
| 额度读取 | `quota_auth_required`、`quota_read_timeout`、`quota_shape_unsupported` | 旧额度带时间保留，其他独立项可更新 |
| 来源和索引 | `source_unreadable`、`source_changed`、`compression_unsupported`、`index_refresh_failed` | 区分回填和故障，不判无负载 |
| 工作边界 | `work_boundary_conflict`、`work_record_unsupported` | 排除冲突项，不清空全部历史；正常旧记录缺边界属于数据状态 |
| 计价容量 | `price_missing`、`pricing_basis_conflict`、`capacity_unavailable` | 仅阻断依赖指标，综合实际工时不因容量缺失而消失 |
| 额度观测 | `quota_observation_conflict`、`quota_reset_ambiguous` | 拒绝跨冲突配对，保留分段缺口 |
| 算法计算 | `aggregation_failed`、`numeric_invalid`、`classification_failed` | 与正常样本不足区分，保留旧统计 |
| 存储发布 | `schema_newer`、`migration_failed`、`storage_write_failed`、`publish_failed` | 不清库、不降级，旧完整结果可读 |
| 调度传输 | `refresh_timeout`、`refresh_cancelled`、`companion_disconnected`、`contract_incompatible` | 有限终态、按策略重计时、支持手动重试 |
| 未知故障 | `internal_error` | 安全归类并暴露，不转换为空数组或成功 |

- 合同至少包含稳定码、阶段、影响指标、是否可重试、任务标识和安全文案；已有公开码沿用，新增码纳入闭合白名单。
- 顶部显示完成／部分更新／更新失败，受影响卡片显示简短原因，一个全局按钮重试。
- 正常有效子样本不加覆盖提示；无可计算值用 `—` 或采集／样本状态。真实故障与保留旧值必须显示错误及时间。
- 每个 catch 必须转换分类状态、继续抛出或记录有界安全诊断；禁止空 catch 和以成功兜底。
- 诊断去重限量，诊断写入失败保留内存状态且不覆盖原故障；不得显示原始异常或私有文件名。
