# Compact model performance

Implement the owner-approved compact preview while preserving all existing work,
raw source records, v5 measurement snapshots and server-side timing semantics.

1. Replace the verbose stacked performance page with aligned model/mode controls,
   responsive paired charts, shared display toggles and complete paginated dialogs.
2. Use exact global reporting windows and bounded pending-result reads; remove
   the independent recurring page refresh. Retain valid previous results and UI
   state during ordinary report replacement; fence obsolete responses.
3. Carry closed, bounded runtime diagnostics separately from the v5 body and
   durable snapshots. Distinguish request, validation, collection and persistence
   failures without exposing source content or paths.
4. Verify focused synthetic boundary tests, UI/local gates, locale mirrors,
   resource closure and documentation. Report unrelated existing failures.
5. Prepare a pinned-runtime Windows candidate, verify real-system measurements in
   the in-app browser and Electron, then observe at least 15 minutes, two automatic
   refreshes and one manual refresh. Record each evidence gate independently.

No migration, raw-record repair, ledger rebuild, release, installation or external
publication is authorized by this plan. The prior working candidate is retained.
