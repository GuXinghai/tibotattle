# Scope and acceptance

Publish independently scoped usage for observed historical plans, including
Plus to Pro upgrades and downgrades under the owner's single-account,
continuous-subscription assumption. Plan labels do not prove account identity.
Preserve original logs, index facts, the all-plan ledger and existing refresh
ownership. Never borrow another plan's capacity, bridge an uncertain transition,
or add the comparison projections back into accounting totals.

1. Generate bounded historical plan lanes from the existing calibration corpus;
   bind each to its own capacity basis, reset cohort and source generation.
2. Validate/cache/project/normalize the lanes through the existing report route.
   Keep valid intervals, expose excluded intervals, and fail each plan separately.
3. Cover upgrades, downgrades, uncertainty, duplicates, generation/cohort mismatch,
   serialization, cancellation and resource bounds with synthetic tests.
4. Reconcile Plus and Pro Lite against one real read snapshot, preserve raw facts,
   prepare a fresh normal-profile Windows candidate, and inspect real reports in
   the in-app browser in both themes and all relevant views.
5. Record actual validation and runtime evidence separately from native rendering,
   installation, signing and public release qualification.
6. If real observation exposes a refresh failure, diagnose its phase and preserve
   the failed receipt before repairing it. Overview indexing uses the existing
   bounded source budget; progress cannot reset the total deadline, and genuine
   hangs must still produce a typed timeout without replacing the last good report.

Implementation and local acceptance are complete. The final normal-profile
candidate passed real Plus/Pro Lite reconciliation, in-app browser checks,
original-record preservation and 1,495 seconds of observation with two automatic
refreshes and one manual refresh. See the [validation record](../qa/2026-10-16-historical-plan-comparisons.md)
for exact artifact, retained existing test failures and evidence boundaries.
